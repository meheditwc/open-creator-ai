# Video Production

One topic in, one publishable package out.

## When to use

- The user knows what the next video is about.
- The user needs a script, or a script plus everything that ships with it.

## The run order

1. **Keyword Research** — check the topic is something people search for. If the
   clusters point somewhere else, follow the clusters.
2. **Video Script** — the timed script: hook in the first five seconds, roadmap,
   three sections, one mid CTA, one end CTA. The word budget comes from the
   target length; read the file at speaking pace before filming.
3. **Shorts Script** — cut the strongest beat into a 20–60 second vertical.
4. **YouTube SEO** — title options with character counts, description with
   chapters, tags, pinned comment.
5. **Thumbnail Brief** — concept, composition and overlay text capped at five
   words, plus the phone-size readability check.
6. **Captions** — paste the script's spoken lines, get SRT + VTT + chapters.
7. **Upload Checklist** — run it before you publish, every time.

## What "done" looks like

- `script.md` with real spoken lines and timestamps, not bullet points.
- `shot-list.csv` you can hand to an editor or follow solo.
- `captions.srt` that matches the script word for word.
- A thumbnail overlay you can read at 120 px wide.

## Rules

- Write the hook before anything else, and never bury the promise after an intro.
- Cut anything that does not serve the one sentence the video promises.
- The titles must clear 60 characters on mobile — the SEO pack shows the count.
