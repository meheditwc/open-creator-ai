# Channel Launch

The first month is not about making videos — it is about choosing a topic you can
survive, then proving you can publish consistently.

## When to use

- The user has no channel yet, or a channel with no clear topic.
- The user says "I don't know what to make videos about".
- The user is restarting a channel that stalled.

## The run order

1. **Niche Finder** — ask for interests/skills, audience and market. The report
   scores niches on demand, competition and stamina, then names the first ten
   videos. Never skip the stamina column: a niche you cannot sustain for 90 days
   is a hobby, not a channel.
2. **Channel Blueprint** — feed the chosen niche in. You get name options with
   availability checks, a tagline, an About section, banner text, a trailer
   script and the starting playlists.
3. **Keyword Research** — seed with the niche. Cluster the keywords into
   video-sized groups, not a 200-line dump.
4. **Content Calendar** — turn the clusters into 30 days of real working titles.

## What "done" looks like

- Two or three niche candidates with a clear winner and a reason.
- A channel name you can say out loud without spelling it.
- Thirty dated slots, each with a title a stranger would click.
- Zero files that say "TBD".

## Rules

- Every deliverable is a real file the creator edits, not advice in chat.
- Prefer narrower: "phone video editing for beginners in Bangladesh" beats
  "video editing".
- If the answers are vague, generate anyway and say in the run notes what to
  tighten next time.
