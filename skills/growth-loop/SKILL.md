# Growth Loop

Growth is a loop, not a launch: publish, read the data, adjust, publish.

## When to use

- The channel has been publishing for a few weeks.
- The user asks "why am I not growing?"
- The user wants monetisation paths or a realistic timeline.

## The run order

1. **Channel Roadmap** — honest 30/90/180-day milestones, the systems that make
   them possible (batching, analytics review, thumbnail testing) and the income
   paths available at the channel's size.
2. **Content Calendar** — rebuild the next 30 days from what actually worked,
   not from what you hoped would work.
3. **Article Writer** — repurpose the best-performing video into a blog post so
   the topic keeps earning search traffic.

## What to look at before regenerating anything

| Metric            | Question                                                 |
| ----------------- | -------------------------------------------------------- |
| Impressions CTR   | Is the thumbnail + title doing its job?                  |
| Average view time | Where do viewers leave? Re-read the script's timestamps. |
| Returning viewers | Is the channel worth subscribing to, or just one video?  |
| Traffic sources   | Search or browse? Each one needs a different fix.        |

## Rules

- No milestone without a number and a date.
- Do not promise monetisation timelines the data cannot support.
- The roadmap names the one thing to change next, not ten.
